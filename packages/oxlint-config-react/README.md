# @perimetre/oxlint-config-react

[`@perimetre/eslint-config-react`](https://github.com/perimetre/framework/tree/main/packages/eslint-config-react) on Oxlint: the rules of hooks and the React Compiler's checks, jsx-a11y, TanStack Query, and our conventions for boolean prop names and prop order. Oxlint runs the hooks, compiler and accessibility rules itself, so only TanStack Query and two prop rules go through ESLint plugins.

## Quick start

Use the prompt in [`@perimetre/oxlint-config-base`](https://github.com/perimetre/framework/tree/main/packages/oxlint-config-base#quick-start). It adds this config when the project uses React.

## Requirements

- React 19
- Oxlint 1.95 or later

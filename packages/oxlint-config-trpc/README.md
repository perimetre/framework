# @perimetre/oxlint-config-trpc

[`@perimetre/eslint-config-trpc`](https://github.com/perimetre/framework/tree/main/packages/eslint-config-trpc) on Oxlint. It turns off the same rules: the type-aware ones that read tRPC's generics as unsafe, and the JSDoc requirements for procedures.

## Quick start

Use the prompt in [`@perimetre/oxlint-config-base`](https://github.com/perimetre/framework/tree/main/packages/oxlint-config-base#quick-start). It adds this config, last, when the project uses tRPC.

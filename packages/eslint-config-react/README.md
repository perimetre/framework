# @perimetre/eslint-config-react

React rules on top of [`@perimetre/eslint-config-base`](https://github.com/perimetre/framework/tree/main/packages/eslint-config-base): the rules of hooks and the React Compiler's checks, jsx-a11y's accessibility rules, TanStack Query's rules, and our conventions for boolean prop names and prop order.

## Quick start

The [ai-toolkit](https://github.com/perimetre/ai-toolkit) project setup installs it in every React project. To add it yourself, use the prompt in [`@perimetre/eslint-config-base`](https://github.com/perimetre/framework/tree/main/packages/eslint-config-base#quick-start). It adds this config when the project uses React.

## Requirements

- React 19
- ESLint 9
